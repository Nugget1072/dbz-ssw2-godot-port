Update the hand-off documents so the next session can continue without this conversation:
- HANDOFF.md: date + part number, what changed (files / sections), how it was verified, open items, next steps.
- docs/HISTORY.md: a short paragraph for this part. CLAUDE.md: only rules / paths / commands that changed.
- docs/QOL_ARCHITECTURE.md + docs/DEBUG_FLAGS.md for new code / flags; design docs' status sections.
- decomp/DATA_NOTES.md "## Session N part M findings (topic)" with H/M/L + addresses, plus a DATA_NOTES_INDEX.md line.
Keep them short: they are read at the start of every session.

melonDS keyboard map used by this project (same on Windows and in the Linux test harness)

  DS button   Key
  ---------   ---------
  A           X
  B           Z
  X           S
  Y           A
  L           Q
  R           W
  Start       Enter
  Select      Backspace
  D-pad       Arrow keys
  Touch       Mouse on the bottom screen
  Hotkeys:    Tab = fast-forward (hold), P = pause, Shift+F1..F8 = save state, F1..F8 = load state

The values in melonDS.toml are Qt key codes. On Windows melonDS 1.1 reads melonDS.toml from the folder
melonDS.exe sits in, so a copy lives in tools/melonDS-1.1-windows-x86_64/melonDS.toml.
OSD messages are turned off so screenshots are clean.
